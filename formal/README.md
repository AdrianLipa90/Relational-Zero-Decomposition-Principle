# Formal verification

Formal kernels and machine-checked lemmas belong here.

Promotion rule:
1. state the exact theorem;
2. list every premise;
3. pin source and toolchain versions;
4. record proof-kernel/CI receipts;
5. update `claims/claim_ledger.json` only after verification.

The RH branch should link to its existing formal kernel rather than duplicate it without provenance.
