# Relational-Zero Decomposition Principle

## A Relational-Zero Decomposition of the Clay Millennium Problems
### Location, Multiplicity, Spectral Gap, Algebraic Realization, Dynamical Avoidance, and Computational Separation

This repository develops the **Relational-Zero Decomposition Principle (RZDP)** as a common structural language for comparing the Clay Millennium problems.

The project does **not** assert that the problems are equivalent. Each branch is treated as a distinct obligation concerning a distinguished zero structure:

- RH — location of zero;
- BSD — multiplicity/index of zero;
- Yang–Mills — spectral isolation/stability of zero;
- Hodge — algebraic realization of zero;
- Navier–Stokes — dynamical avoidance of a singular boundary;
- P vs NP — computational/resource separation.

The Riemann Hypothesis is the first worked reference case. Its exact carried status is **A0 => RH**, where A0 is the explicitly stated Universal Relational-Zero Axiom.

## Proof-status discipline

Every mathematical claim must be tagged as one of:

- THEOREM
- CONDITIONAL
- REDUCTION
- OPEN_BRIDGE

No Q.E.D. may be promoted from analogy, shared notation, numerical evidence, or structural resemblance alone.

See `claims/claim_ledger.json` for claim state and `provenance/GREMLIN_PROVENANCE.md` for provenance/authority separation.
